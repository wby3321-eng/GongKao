## 🚀 GitHub Pages 流程及部署

### 架构概览

```
本地新增/修改文件
      ↓
git commit + git push
      ↓
GitHub Actions 自动触发
      ├─ 1. 更新 data.json（扫描目录生成树状数据）
      └─ 2. 部署到 GitHub Pages
      ↓
https://wby3321-eng.github.io/GongKao/
```

### 目录约定

```
仓库根目录/
├── {省份名称}/          ← 省份（如 广东、湖南）
│   ├── {分类}/          ← 考试类别（如 行测、申论、重点知识）
│   │   ├── {子分类}/    ← 可选（如 真题、答案）
│   │   │   └── *.pdf / *.docx
│   │   └── *.pdf        ← 也可直接放文件
```

### 新增内容

只需两步：

```bash
# 1. 按目录约定把文件放到对应位置
mkdir -p 湖南/行测
cp 2027湖南行测.pdf 湖南/行测/

# 2. 提交推送 —— 完事，GitHub 全自动处理
git add -A
git commit -m "新增 2027 湖南行测"
git push
```

等待约 30 秒，网站自动更新。

### 两个 GitHub Actions 工作流

| 工作流 | 作用 | 触发时机 |
|--------|------|---------|
| `.github/workflows/update-data.yml` | 运行 `scripts/gen-data.py` 扫描目录，自动更新 `data.json` | push 时（data.json 变更才触发回写） |
| `.github/workflows/deploy-pages.yml` | 将仓库内容发布到 GitHub Pages | push 时 |

### 前端渲染

- `data.json` 由脚本自动生成，描述完整的目录树结构
- 纯 HTML + JS 渲染，无任何构建步骤
- 点击文件 → 浏览器原生打开（PDF 直接预览，不下载）
- 点击文件夹 → 展开/折叠

### 本地调试

```bash
python3 scripts/gen-data.py              # 生成 data.json
python3 -m http.server 8080              # 启动本地服务
open http://localhost:8080
```

### Pages 设置（一次性）

1. 打开 https://github.com/wby3321-eng/GongKao/settings/pages
2. Source 选择 **GitHub Actions**
3. 保存即可（后续全自动）
