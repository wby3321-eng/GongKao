# 周期余数

```
总数量 ÷ 周期T= 组数······余数R
```
```
问题：只有周四和周六有拉丁舞蹈课,如果你购买了一张月卡，那么你可以在一个月内（31天）最多参加多少次舞蹈

解答：最多上10次

七天为一个周期,一周内可以上两次舞蹈课
31÷7=4余3天 至少可以上4*2 = 8次课程
如果剩余的三天分别是周四、周五、周六，那么在余下的三天内最多以上2次舞蹈课
总共最多上10次舞蹈
```
